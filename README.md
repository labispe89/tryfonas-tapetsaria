# Τρύφωνας Σπυρίδων – Ταπετσαρίες Επίπλων

Στατική, responsive ιστοσελίδα για το `tryfonastapetsaria.gr`, έτοιμη για GitHub Pages.

## Δημοσίευση

1. Ανέβασε όλα τα αρχεία στη ρίζα του repository.
2. Στο GitHub άνοιξε **Settings → Pages**.
3. Επίλεξε **Deploy from a branch**, branch `main`, folder `/ (root)`.
4. Η πρώτη δημοσίευση χρησιμοποιεί τον προσωρινό σύνδεσμο του GitHub Pages.
5. Όταν είμαστε έτοιμοι να συνδέσουμε το domain, μετονόμασε το `CNAME.example` σε `CNAME`.
6. Ενεργοποίησε το **Enforce HTTPS** όταν το GitHub επιβεβαιώσει το domain.

> Η σύνδεση του domain απαιτεί μόνο τις εγγραφές web που θα υποδείξει το GitHub. Οι υπάρχουσες MX/TXT/SPF/DMARC εγγραφές email δεν πρέπει να τροποποιηθούν.
